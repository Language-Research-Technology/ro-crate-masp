RO-Crate MASP example profiles and schemas

Machine Actionable Schemas and Profiles (MASP) for RO-Crate. Profiles say what a conforming crate must contain and can be used to validate one; schemas define vocabulary terms, some converted from OWL ontologies.

Source, validator and build tools: ro-crate-masp on GitHub.

Examples only. These profiles and schemas are working examples for developing and testing MASP. This is not their permanent home: each will eventually be published and maintained elsewhere, so don't rely on these copies or their URLs.
